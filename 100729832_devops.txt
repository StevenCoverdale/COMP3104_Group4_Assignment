COMP3104 - Introduction to DevOps  
George Brown College

Course Description
------------------
This course introduces students to the principles and practices of DevOps, focusing on collaboration between development and operations teams, automation, continuous integration/continuous deployment (CI/CD), and cloud technologies.

Topics Covered
--------------
- DevOps fundamentals
- Version control systems (e.g., Git)
- Continuous integration and deployment
- Infrastructure as code
- Monitoring and logging
- Cloud computing basics

Prerequisites
-------------
Basic programming knowledge

Credits
-------
3

For more information, visit:  
https://www.georgebrown.ca/programs-and-courses/courses/comp3104

Learning Outcomes
-----------------
Upon successful completion of this course, students will be able to:
- Explain the core concepts and benefits of DevOps.
- Use version control systems to manage code collaboratively.
- Implement CI/CD pipelines for automated software delivery.
- Apply infrastructure as code principles using modern tools.
- Monitor and troubleshoot applications in production environments.
- Understand the role of cloud platforms in DevOps workflows.

Assessment Methods
------------------
- Quizzes and assignments
- Group projects
- Practical labs
- Final exam

Recommended Texts and Resources
-------------------------------
- "The DevOps Handbook" by Gene Kim et al.
